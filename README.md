## 🌌 Overview

NEXORA is a visually stunning cyberpunk-inspired landing page built using **HTML5, CSS3, and JavaScript**. The project combines futuristic design principles, neon aesthetics, smooth animations, and responsive layouts to create an engaging user experience.

Designed to resemble an advanced AI operating system from the year 2050, NEXORA delivers a premium user interface with modern web technologies.
